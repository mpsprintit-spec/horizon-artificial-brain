# Ordered observations (H11)

## Contract

Serving runtimes use `ordered-observation-v1`. An observation carries ordered
simultaneous population frames for stimulus, context and data. Repeated frames
and stream boundaries survive grounding; IDs inside a frame form an unordered
set. Context and data precede stimulus in recurrent microsteps inside the same
journal revision and physical timestamp. No grammatical roles, word-specific
rules, semantic parser, LLM or separate answer store are introduced.

`ObservationInput` derives these frames from its token groups. Unique grounding
provenance remains deduplicated, but every occurrence enters the trace. Raw
`StimulusNodeIDs` still means one simultaneous population. Explicit numeric
sequences use `Event.NeuralTrace`, referencing already grounded neurons. Written
observations without explicit context may use the preceding stimulus trace as
context, including after checkpoint recovery. Physical sensor samples do not
implicitly replay their predecessor into the current measurement.

Learning accepts `Experience.ContextSequence` and `DataSequence` alongside the
existing lexical `Sequence`, or corresponding `NeuralContext`, `NeuralData` and
`NeuralSequence` population frames. Lexical and numeric forms cannot be mixed in
one stream. The final stimulus frame is the supervised outcome. Validation and
deep copying precede the write-ahead boundary.

## Neural prediction

Ordered patterns retain **full populations**, not only their anchor IDs: two
sensor populations can share an anchor while containing different other units.
The exact ordered trace and result identify reinforcement, preserving repeated
frames even when two patterns have the same result. Legacy member-set learning
remains unchanged for historical replay.

The existing pattern substrate supplies learned conditional prediction channels.
A matching suffix supports its learned result; competing results with the same
stimulus ingredients receive positional/contextual support only when their
ordered evidence matches. Shorter matches retain proportionally less support.
Pattern strength uses learned weight, calibrated confidence and frequency with
the existing .35 cap. If no pattern matches, ordinary neural priors remain.
This modifies prediction, not the current observed activation. These values are
neural activation strengths, not normalized answer probabilities.

## Persistence

New records use journal **schema 3**, with `dynamics_encoding`. Readers accept
schemas 1, 2 and 3. Absent dynamics means historical simultaneous/member-set
behavior; each replayed record selects its own contract on an isolated runtime.
The serving default is restored after replay. Sensor intent and commit markers
must agree on dynamics and surface contracts.

Checkpoint **v8** authenticates the last ordered trace and full learned pattern
populations. Anchored v7 checkpoints still support suffix recovery. V4–v6 retain
their previous detached import restrictions. A pre-v8 envelope carrying ordered
state, unknown dynamics or unknown population references is rejected before
changing the restore target. Keep original files for rollback; old binaries must
not read new schema-3 journals or v8 checkpoints. Brain-only exports are not a
complete restart boundary.

Immutable schema-1 and schema-2 fixtures were produced by actual PR29 and PR30
code. Tests compare the complete logical state and next thought with those
references, normalizing only the candidate checkpoint envelope version back to
v7 for checksum comparison. Original fixture checksums are never regenerated by
the candidate. The v7 checksum algorithm also covers v8, including its schema
version and newly present fields.

## Evidence and limits

`ordered_prediction_test.go` checks all six audit contrasts (actor reversal,
negation/location reversal and temporal reversal) with their supervised target
neurons at three randomized vocabulary insertion orders. It checks prediction
margins rather than state inequality alone. Balanced exposure order, untrained
controls, shuffled labels and pattern ablation distinguish learned conditional
prediction from incidental state differences. Explicit context and a context
observation followed by a question both work; the latter resumes across restart.

Other tests cover repeated-token permutations, the same result under distinct
orders, known suffixes inside new prefixes, context/data boundaries, numeric
populations obtained through the physical sensor boundary, within-population
permutation invariance, native `Pulse`, managed HTTP ingress, genesis/suffix
replay, continuation after recovery, invalid input, uncertain append and schema
downgrade rejection. Existing compound inquiry, import and retired-runtime
regressions remain part of the full suite.

This establishes ordered neural processing and trained conditional prediction.
It does **not** establish general actor/role binding for unseen names, novel
grammar, negation semantics, temporal reasoning, or reliable selected natural
language answers. Prefix composition is limited suffix transfer. The generic
answer ranker still ranks current activity. H10 long-history context retention
and H23 independent generalization/corpus evaluation remain open.
