# Internal numerical resolution and diagnosis, V5

Research only; opt in with `NeuralCompositionResolutionV5`. The default remains
V1. There is no trained-memory migration from V4, production activation, market
execution integration, or claim of general semantic identity.

The adapter supplies a numerical question and up to 64 ordered rows, each with
six bounded measurements plus explicit presence. The lag codec retains all seven
coordinates, so a missing input is distinguishable from a measured zero. Input
coordinates and question-code neurons are scaffolding; count them separately
from learned N circuits. Different raw input alone does not allocate a circuit.

`CompositionExposure.Resolution` supplies bounded `Fit` and `Check` observations
with outcomes, observation times and episode provenance. Check episode IDs must
be disjoint from fit IDs. This check does not establish statistical independence.
All outcomes must already be observed at the exposure's after-time. The tested
curriculum uses signed predicate outcomes -1/+1. Continuous predictions and a
joint world-state transition model are not validated by these tests.

Each learned N is a projection or a product of earlier learned responses, with
an observed resolution and a learned center. Directions, centers, resolution,
query readouts and observed-check RMSE are signed canonical dynamic synapses.
The N state holds only topology, numerical experience witnesses and diagnosis.
There is no external weight cache or answer lookup. Current N codes are computed
from those synapses; native thinking also receives the learned N activations.

For each lesson the engine evaluates readout correction, finer existing N,
additional discriminators/boundaries, and products of existing N. Projection
directions use centered response residuals. Proposed centers and resolutions are
learned from response contrasts. The current numerical resolution policy is the
smallest observed projected contrast divided by 16, bounded to [1e-9,7.99].
Those constants are engineering choices, not a universal law or biological claim.

Geometry alone never authorizes growth or declares meaning identical. A new
boundary on a geometrically parallel axis can be necessary. Functional redundancy
is checked on supplied examples; signed reuse is allowed. This is conditional
empirical reuse, not proof that all unseen contexts have identical meaning.
Existing circuits are not globally merged. Legacy general-purpose projectors
retain their older behavior; V5 uses this separate opt-in numerical path.

A candidate must improve the current observed check error, avoid increasing
retained mean error for each query, and avoid flipping an old accepted-correct
binary distinction. Wrong or uncertain residuals are not individually frozen.
Only the winning validated candidate is installed, exactly, in the canonical
synapses. Contradictory identical observations produce uncertainty rather than
inventing more neurons. Rejected candidates allocate no knowledge circuits or
question-code neurons. Sources are allocated only as needed by committed circuits.

`NDiagnosis` records candidate family, feature ID for resolution trials, errors,
retention violations and growth. These are computational bottleneck diagnoses
among engineered candidates, not proof of a hidden physical market cause.
Error/inquiry/curiosity signals persist with the Brain. The witness budget is
128, balanced across up to 32 queries; the circuit ceiling is 32. These are
resource limits, not neuron quotas per object, and do not guarantee indefinite
retention. Pruning or globally merging existing N is not implemented.

Validated N parameter weights are protected against uncoordinated passive
memory decay; support metadata still decays. This preserves the direction /
resolution numerical contract. A learned forgetting/retirement policy remains
future work. No-op inference neither grows neurons nor updates knowledge.

`ObserveCompositionInput(CompositionPerception, time)` durably records actual
numeric perception and updates sequence continuation without projecting another
population for every raw appearance. Checkpoint, full journal replay and ordinary
`CognitiveThink` preserve/use the sequence. `numeric-prediction` readouts contain
no motor proposal. Their observed-check RMSE and confidence are not calibrated
probabilities, and acceptance is not authorization to act.

Tests cover fine distinctions, irrelevant changes, conditional/inverse readings,
a new boundary on an old axis, learned composition, contribution ablation,
balanced retention, unsupported corrections, conflicting/future evidence,
malformed checkpoint rejection, native N activation, checkpoint and full replay.
The optional historical integration test requires `HORIZON_N_DATASET` explicitly;
it reads past charts only and does not download prices or test future trading.

Remaining audit gaps include adaptive content attention in the older RNN,
end-to-end multi-step future-state learning, probability calibration, unlimited
retention and identity, production serving, and V4 trained-memory migration.
