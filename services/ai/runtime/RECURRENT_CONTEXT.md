# Bounded recurrent context (H10)

For current provenance accounting and checkpoint v12, see [EVIDENCE_PROVENANCE.md](EVIDENCE_PROVENANCE.md).

## Mechanism and limits

The recurrent context contract introduced by `recurrent-context-v1` is retained
by current `evidence-provenance-v1` serving runtimes (see [LOCAL_PLASTICITY.md](LOCAL_PLASTICITY.md)
and [MEMORY_TIME.md](MEMORY_TIME.md)). Actual observed stimulus population
frames retain transient neural eligibility on the same persistent Brain. A
learned ordered pattern can use eligible earlier populations to supply its
missing stimulus prefix or context. Retrieval selects the most recent ordered
completion, including across intervening observations. Current input order and
explicit context/data boundaries remain mandatory.

Prior history is not injected wholesale into current observed activity. It
modulates the learned pattern prediction channels. This makes X,A and Y,A
predict B and C after balanced X→A→B / Y→A→C training, while a cue without learned
context support retains ordinary neural priors. The generic answer ranker still
ranks current activity; this change does not establish selected language answers.

Eligibility has explicit engineering bounds:

| Parameter | Value |
|---|---:|
| Retained population frames | 64 |
| Total retained member IDs | 4,096 |
| Maximum eligible physical age | 120 seconds |
| Eligibility half-life | 30 seconds |
| Intervening-frame retention factor | 0.9 |
| Relative competition exponent | 4 |

For a completion, `q = 2^(-oldest_age/30s) * 0.9^skipped_frames` and
`score = matched_pattern_length * q`. Its predictive support is
`q * (score/best_score)^4`. Learned weight, calibrated confidence and frequency
supply the existing bounded pattern strength. These are chosen engineering
parameters, not measured biological constants or a claimed optimal policy.

Both time and interference reduce support. Expired/future evidence is ineligible;
expired samples are physically pruned at the next observation. Capacity evicts
whole older populations. An individually oversized population is not partially
retained. Internal thought does not append observations or refresh their clocks,
and excludes its own latest cue from the prior-context search. The memory stores
only observed neural IDs/times/order, not labels, targets or copied Brain graphs.
Learned mappings remain in the existing synapses and pattern substrate.

## Episode boundaries

`Event.EpisodeID` scopes context; `Event.ResetContext` deliberately starts fresh
context at a durable observation boundary. HTTP `ObservationEnvelope.SessionID`
and numeric `SensorObservation.SessionID` map to this episode identity. Native
`PerceptionSignal` exposes `SessionID` and `ResetContext`, forwarded by the facade.
Numeric sensor resets use a changed session identity; a reset flag on the
internal sensor event is rejected because sensor replay derives its event from
the sensor payload. Changing an identity, including between scoped and unscoped input, clears the
previous eligibility. An empty ID is one bounded unscoped stream, not automatic
real-world episode detection.

The same boundary also clears the runtime's temporal observation predecessor,
preventing accidental cross-episode transition learning. It stops comparing the
new input to the previous episode's implicit prediction. Explicit pre-action
prediction overrides retain their separate causal meaning. Canonical long-term
knowledge, action bindings and evidence are retained. A backward observation
clock resets transient context and the temporal predecessor instead of using
future observations as context; physical sensor timestamp validation is retained.

Adapter/episode provenance is checked before WAL append or grounding. A failed
append cannot reset the context, alter its predecessor or ground new input.

## Versioned continuation

Journal schema **3** remains sufficient: the new dynamics string is mandatory
for episode controls and is rejected by older readers' dynamics validation.
Empty dynamics retains historical simultaneous behavior; `ordered-observation-v1`
retains the exact H11 behavior. Replay selects each recorded contract privately,
then restores the current serving default.

Checkpoint **v9** authenticates eligibility, episode, frame chronology and cue
position alongside the existing complete continuation state. Bounds and neuron
references are validated before changing a restore target. Pre-v9 envelopes
cannot carry this state. Anchored v7/v8/v9/v10 checkpoints support offset recovery;
v4–v6 retain their existing detached import restrictions. Brain-only exports do
not preserve this continuation state.

The immutable `testdata/ordered_dynamics_v1` fixture was generated by actual PR31
commit `0f9a4651f1d31e6f1ceeb0ca4d66fddafeafa4dc` using Go 1.22.12. It verifies full
logical-state checksums and the next thought/post-thought state from genesis and
an anchored v8 prefix. Only the new envelope version is normalized to v8 for
comparison; fixture checksums are not regenerated by the candidate. Existing
schema-1/2 fixtures continue to verify their original behavior. Historical state
without eligibility resumes its H11 next thought under the recorded dynamics; new observations start the new
bounded context rather than inventing historical observation times.

## Evidence and open work

On PR31, all 12 X,A / Y,A probes (three vocabulary insertion permutations, with
and without two distractors) had prediction margin zero. The new tests require
opposite learned outcome margins above 0.2. Other tests cover longer prefixes
across observations, delay/expiry, capacity eviction, recent competing contexts,
untrained/shuffled-label/history-ablation controls, numeric vector populations,
episode changes/resets, temporal-link isolation, clock rollback, thought without
refresh, detached snapshots, restart, full genesis/suffix continuation, native
Pulse, managed HTTP, invalid checkpoints/contracts and uncertain writes.

This establishes bounded learned predictive context on these probes. Unseen
actor/role binding, arbitrary grammar, semantic answer selection, automatic
real-world episode segmentation and long-range retrieval beyond these bounds
remain unproven. H08 passive retention is addressed in MEMORY_TIME.md and the
reproduced H09 interference in LOCAL_PLASTICITY.md. H12 evidence accounting is
addressed in OBSERVED_FEEDBACK.md. Bounded H13 calibration is covered in EVIDENCE_UNCERTAINTY.md;
H23 independent language/generalization evaluation retain their own acceptance
criteria.
