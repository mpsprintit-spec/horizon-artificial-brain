This is a new, explicitly registered stage within S2-R4. It retains every
preceding stage and starts all models again from the mandatory original R2

## Why the earlier information claim is insufficient

The original offline current-state comparator conditioned on nine population
means, not all 36 measured neurons. A supplementary **development-only** audit
using all 36 values found only 2.48% additional history benefit, CI95
[-3.83%,6.42%]. Giving spatial contrasts their own Fit-only scaling reduced
the additional benefit to 0.276%, CI95 [-1.568%,1.372%]. Thus the earlier 26.28%
reduced-state gain is not evidence of conditional information beyond the
complete current neural state. That claim is withdrawn at the full-state level.
The shared population stimulus lets 2% carried poststate expose previous gain
through otherwise noise-free within-population contrasts.

Revise the experience generator, not the learner's answers: each existing
neuron receives an independent uniform stimulus perturbation of width .08,
clipped to [.001,.9], in addition to its population drive. It still carries
.02 actual previous poststate and executes the same real native operations.
Hidden persistent/IID gain, S1, observed target law and input codec are unchanged.
Neither gain nor regime is exposed to Horizon.

The complete-state diagnostic represents current 36 measurements invertibly
as nine means plus 36 centered spatial contrasts, then previous nine state
projections, three forecasts and operation/history flags. Contrast scaling
uses Fit only. Polynomial ridge uses an equivalent sample-space dual solve;
RBF controls remain offline. This is diagnostic mathematics, not a runtime
network. All 57 continuous current/past/forecast coordinates also enter the
target-blind nearest-neighbor conditional permutation; categorical context
matching and ten replicate seeds remain unchanged. Matching remains approximate.

Before native v4 training, full-state development on independent audit
streams passes the **unchanged >=10% conditional-benefit gate**: current-only
RMSE .07628616, history .05720055, **25.0184%**, CI95 [19.2821%,30.5330%].
IID benefit 1.9043%, CI95 [-1.1301%,4.4485%], not a demonstrated gain. All
development target/history provenance checks pass. Previous environments and
their reduced/full-state statistics are archived, not pooled into this result.

## Time, retention and computation

Earlier v3 raw A–E1 audit reveals a physical-memory time confound: numerical
commands settle native passive decay, whereas native observation commands
do not. A control matching journal revision did not match `applied_at`.
Supplementary elapsed-time normalization on detached evaluation controls is
reported separately and never erases the original failure or promotes a model.

For v4 use strictly increasing **simulated nanosecond event ticks**, anchored
at the original source time. This isolates learned changes from unrelated
passive ageing, just as earlier S2 fixed-time experiments controlled time.
It does not modify the native decay law, threshold, actual gain law or measured
wall-clock performance. Time persistence/correlation is in ordered operations;
no claim of nanosecond real-world execution is made. The 1e-7 retention bound
is unchanged and remains independently tested on every model.

Fresh behavioral oracle copies may omit only the checkpoint envelope's old
command-dedup index/journal anchor after the original complete checkpoint is
verified. All canonical Brain bytes, learned parameters, recurrent state,
clock, policy and sequence are preserved. These copies are **not recovery
artifacts** and cannot be used for continuation. A strict parity regression
against an already measured full v3 A–E1 oracle must pass with zero difference
before this evaluation speed optimization is used. All cases/thresholds remain;
complete checkpoints/WAL and exact native recovery tests never omit metadata.
